# Mystery Hotel Escape Room

A story-driven Java Swing escape room game.

## Language
- Game UI and story: German
- Source code: English

## Current concept
You wake up in a locked hotel room. Investigate objects, connect clues, solve puzzles, collect items, and escape.

## Planned features
- Atmospheric Swing UI
- Interactive room objects
- Puzzle progression
- Inventory
- Attempts and timer
- Multiple rooms
- Sound and visual feedback

## Tech
- Java
- Swing
- Maven/standard JDK tooling (planned)

## Status
Early development. The first goal is a playable, attractive single-room prototype.
